# Java Basic Practice

Real standalone Java programs for beginners. These files are suitable for Eclipse because each file contains one public class whose name matches the filename.

## Topics

- Hello World
- Variables
- User input
- Even and odd
- Positive, negative, and zero
- Voting age check
- Calculator
- Multiplication table
- Student grade calculator
- Array average
- Classes and objects
- Fahrenheit to Celsius
- Student information

## Run in Eclipse

- Create or open a Java project in Eclipse.
- Right-click `src` and choose **Import > File System**, or copy these `.java` files into the `src` folder.
- Open any file, such as `EvenOdd.java`.
- Right-click inside the editor and choose **Run As > Java Application**.

Each program is independent and has its own `main` method. No fake placeholder code is included.

## Methods and Functions

- `FunctionGreeting.java` — Basic method
- `FunctionAddNumbers.java` — Method with parameters and return value
- `FunctionEvenOdd.java` — Boolean method
- `FunctionFactorial.java` — Method with a loop
- `FunctionLargest.java` — Method for finding the largest number

## Advanced Practice

- `AdvancedStringPalindrome.java` — String comparison with a palindrome method

- `AdvancedBubbleSort.java` — Sorting an array with bubble sort
